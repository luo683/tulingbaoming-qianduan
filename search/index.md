## 💬 常见问答

## 大一新生应该先学哪门编程语言？ | 推荐 Python 或 C 语言。Python 语法简单，能让新手快速建立编程思维和成就感；C 语言紧贴底层，有助于理解内存和指针，为后续学操作系统打基础。两者掌握后，再学 Java/C++ 会非常快。

## 学社对基础有要求吗？我只会写 Hello World 能加入吗？ | 可以。我们更看重学习热情和投入意愿。招新笔试主要考察基本的逻辑思维和简单的编程题，不会超出大一上学期内容。加入后会有 mentor 制度帮助新人快速上手。

## 想打 ACM 竞赛，应该怎么准备？ | 三步走：1. 刷 LeetCode Hot 100，掌握常见数据结构和算法模板2. 上 Codeforces 打周赛，从 Div.3 开始逐步升级3. 组队参加校赛/省赛积累团队配合经验学社内有竞赛训练群，每周组织模拟赛 + 讲题。

## 前端和后端哪个方向更好找工作？ | 两者需求量都很大，关键看你兴趣：前端：直观（写出来就能看到），入门快，但技术迭代非常快，需要持续学习后端：抽象一些，需要理解系统设计、数据库、并发等，但技术栈相对稳定建议大一大二两个方向都体验一下，再做选择。

## 学社的活动频率是怎样的？会不会影响学习？ | 每周 1-2 次活动，通常是周三晚上技术分享 + 周末 Workshop。不强制参加，来去自由。我们的理念是 "学习为主，社团为辅"——活动是为学习服务的，不是负担。

## 怎么加入学社的项目组做实战？ | 每学期初会有项目组招募，在学社群内发布项目方向和招人要求。也可以自己 initiate 项目在学社内招人组队。之前有过：课程评价平台（全栈）、ACM 训练 OJ 系统、学社官网（这个网站本身）。

## GitHub Copilot / AI 辅助编程会不会让人变菜？ | 善用则利，滥用则废。Copilot 适合用来加速重复性代码、快速查 API 用法、写测试用例。但初学者如果什么都不想就让 AI 写，会跳过"自己思考算法 → 写代码 → debug"这个最重要的训练过程。建议：先自己写，再让 AI review；而不是让 AI 写，你再改。
